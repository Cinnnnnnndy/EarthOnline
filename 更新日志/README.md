# 项目更新日志

每天北京时间 00:00 自动把前一天在 Claude 项目「EarthOnline」里的对话（项目主聊天 + 各个线程）导出到这里，一天一个文件，
用来在上下文被压缩之后追溯当时的思路和决定。

- 文件名：`YYYY-MM-DD.md`（按北京时间分天）
- 每个文件先写「当天摘要」（做了什么、定了什么、还没定的），再按线程列出原始对话
- Cindy 的话一字不改；Claude 的回复保留正文；路由、状态卡之类的系统消息只保留关键的几条
- 当天没有对话就不生成文件
