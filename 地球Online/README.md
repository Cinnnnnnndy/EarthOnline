# 地球Online

> 地球Online：一本会随旅程长出世界的魔法书。按天排行程，行程变成一座风格化 3D CG 的玩具微缩小城（画风定案：世界风 CG），站点是一栋栋可以搭的积木建筑，一个圆润的小人替你从第一站走到最后一站；旅行结束，合上书就是日记。
> 鸿蒙（HarmonyOS NEXT）首发，iOS 同步；重点机型 Pura X Max 与 iPhone Duo。
> 产品名「地球Online」（第三轮定名）；「魔法书」保留为旅程的隐喻：一段旅程 = 一本书。
